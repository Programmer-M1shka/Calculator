# 🧮 C# Console Calculator

A simple and interactive **C# console application** that performs basic arithmetic operations — addition, subtraction, multiplication, and division — directly in your terminal.

---

## 🎯 Project Description

This project demonstrates how to build a basic calculator using **C#** and the **.NET Console**.  
It allows the user to input two numbers and choose an operator (`+`, `-`, `*`, `/`).  
The program then calculates and displays the result interactively.

---

## ✨ Features

- ➕ **Addition**
- ➖ **Subtraction**
- ✖️ **Multiplication**
- ➗ **Division (with zero-check validation)**
- 💬 **Interactive input and output**
- ⚠️ **Error handling for invalid operators and division by zero**
- 🧠 **Simple, clear logic — perfect for beginners learning C#**

---

## 🧩 How It Works

1. **Start the Program**  
   The console displays a welcome message:  

2. **Enter Numbers**  
You’ll be asked to enter two numbers (the program supports decimal values).

3. **Choose an Operator**  
The program lets you choose from: `+`, `-`, `*`, or `/`.

4. **Perform Calculation**  
The result is calculated based on your input and displayed clearly in the console.

5. **Handle Errors**  
- If you divide by zero → it shows a warning message.  
- If you enter an invalid operator → it notifies you and ends the program.

6. **Exit**  
After displaying the result, the calculator ends with a friendly goodbye message.
